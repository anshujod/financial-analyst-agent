# Financial Analyst Agent

An agent that answers questions about a company's 10-K filing (NVIDIA FY2024) by retrieving relevant filing sections through LLM-driven tree search and generating grounded, analyst-voice answers with a Qwen2.5-3B-Instruct model fine-tuned via QLoRA. Includes a calculator tool for computations like YoY growth so the agent computes rather than hallucinates figures.
